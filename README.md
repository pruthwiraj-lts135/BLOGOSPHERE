Blogosphere 🌐

A modern and responsive blog application built using HTML, CSS, and JavaScript.

Blogosphere provides a simple platform where users can explore blogs, create and publish their own content, save drafts, and interact through comments.

🚀 Features
🏠 Responsive Home Page
🔐 Login and Registration Pages
📊 User Dashboard
✍️ Create and Publish Blogs
💾 Save Blog Drafts using Local Storage
🖼️ Cover Image Upload and Preview
📝 Basic Rich Text Editor
🔍 Blog Search
💬 Comment Section
🌙 Light and Dark Theme Toggle
📱 Responsive Navigation with Hamburger Menu
📄 Pages
Home – Landing page with featured/latest blog content.
Explore – Browse and search available blog posts.
Blog Details – Read complete blog articles and post comments.
Login – User login interface.
Register – User registration interface.
Dashboard – View blog statistics and published content.
Create Blog – Create, save, and publish blog posts.
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and responsive design
JavaScript – Interactivity and functionality
Local Storage – Saving drafts and published blog data locally

✨ Key Functionality
Blog Creation

Users can:

Add a blog title
Select a category
Upload a cover image
Write content using a basic rich text editor
Add tags
Save a draft
Publish a blog
Search

Users can search for blog posts on the Explore page using relevant keywords.

Theme Toggle

The application includes a light and dark theme toggle for a better user experience.

Comments

Users can enter their name and add comments to blog posts.

💻 How to Run the Project
Clone this repository:
git clone https://github.com/YOUR-USERNAME/Blogosphere.git
Open the project folder.
Open index.html in your browser.

No additional installation or dependencies are required.
